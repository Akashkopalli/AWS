# AWS S3 Static Website

A simple static HTML website hosted publicly using Amazon S3. This project demonstrates the core concepts of cloud storage, static web hosting, and Identity and Access Management (IAM) bucket policies.

## 🛠️ Tech Stack
* **Frontend:** HTML5
* **Cloud Provider:** Amazon Web Services (AWS)
* **Services Used:** Amazon S3 (Simple Storage Service)

## 📋 Project Objective
The goal of this project is to successfully deploy a basic webpage to the internet using AWS. The deployment process involved:
1. Creating an Amazon S3 bucket with a globally unique name.
2. Uploading the `index.html` file to the root of the bucket.
3. Enabling the **Static Website Hosting** feature.
4. Configuring **Block Public Access** settings to allow external traffic.
5. Writing and applying a custom **JSON Bucket Policy** to grant `s3:GetObject` permissions for public read access.
